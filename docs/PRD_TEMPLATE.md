# 一页 PRD 模板（AI 功能）

> 原则：一页写完。写不下的部分拆到附录，不要把 PRD 变成需求池。

## 1. 目标用户与真实任务

用户是谁；他现在为了完成哪件事付出什么代价；当前替代方案是什么。写**任务**，不写「赋能」「提效」这类没有主语的词。

## 2. 需求四道门

引用 `REQUIREMENT_GATES.md` 的四个答案与证据，写明结论是立项还是暂缓。

## 3. 能力边界与兜底

| 项 | 内容 |
| --- | --- |
| 只做什么 | ______ |
| 明确不做什么 | ______ |
| 模型依据 | 只用检索到的资料 / 可用常识补全（二选一，写清楚） |
| 引用与可追溯 | 每条结论是否必须附来源 |
| 低置信行为 | 拒答 / 转人工 / 降级到确定性工具 |
| 高风险结论 | 哪些必须人工复核 |

幻觉不追求「消灭」，而是设计**可接受的风险边界**：强制引用、置信度阈值、人工确认入口、明确告知局限。

## 4. 指标与上线门槛

见 `METRICS.md` 的四层指标表。每项写当前基线、目标值和验收方式；没有基线的标「待测」，不要编数字。

## 5. 成本测算

用 `src/cost_model.py` 算**单个成功任务成本**，附方案对比表与假设参数。注意人工兜底往往是成本大头。

## 6. 灰度与监控

灰度范围、观测字段（检索片段、提示词版本、模型、token、延迟、答案）、坏例回流评测集的闭环、回滚条件。

## 7. 明确不做

列出本次范围外的事，尤其是：微调、多租户、全量语料入上下文、收录非自有版权资料。
